# Mr J's Maths Check

A small web app for learners of Mr Jantjies Maths Classes. A learner scans the
QR code for a worksheet, records the mark and how each question went (level 1,
2 or 3), and sends the result to the tutor on WhatsApp.

* It works offline and can be added to the home screen.
* There are no accounts, adverts or tracking. Everything stays on the phone
  until the learner taps Send. See [PRIVACY.md](PRIVACY.md).
* This repository only holds the app's own files. No learner data is ever
  stored here.
